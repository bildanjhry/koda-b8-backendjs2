Program Management notes berbasis web dimana user dapat menyimpan, mengedit dan menghapus note

### Features:
- Add note
- Updated note
- Pin note
- Delete note

### API Endpoints:
| Method | Endpoint | 
|--------|----------|
| GET | /users |
| GET | /users/:id |
| POST | /register |
| POST | /login |
| POST | /notes/:id |
| DELETE | /notes/:idUser/:id |
